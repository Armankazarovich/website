# ARAY AI Fill Pattern

Дата фиксации: 02.05.2026

Цель: в каждом важном разделе админки дать человеку кнопку "Заполнить с Араем", но сделать это одной системой, а не россыпью случайных кнопок.

## Закон

1. Одна общая кнопка `ArayFillButton` для форм.
2. Один общий endpoint `POST /api/admin/aray/fill`.
3. Arai не сохраняет данные сам без явного действия человека.
4. Arai возвращает draft-поля и короткое объяснение, что он изменил.
5. Форма показывает предпросмотр, человек нажимает "Применить" или "Отмена".
6. Обычная кнопка "Сохранить" остается финальным действием владельца/менеджера.
7. Все действия пишутся в журнал: кто попросил, какой раздел, какие поля предложены, применено или отменено.

## Где включаем первым кругом

- Категории: SEO title, SEO description, slug, короткое описание.
- Товары: описание, SEO, характеристики, alt для фото.
- Медиабиблиотека: alt-текст, теги, назначение "личное/бизнес/SEO".
- Статьи: заголовок, структура, SEO, краткое описание.
- Услуги: описание, выгоды, заявки, SEO.
- Акции: текст акции, баннерный текст, условия, товары для акции.
- Рассылки: тема письма, текст, push-версия, сегмент получателей.

## Что Arai получает

```ts
type ArayFillRequest = {
  section:
    | "category"
    | "product"
    | "media"
    | "post"
    | "service"
    | "promotion"
    | "email";
  intent: "seo" | "description" | "alt" | "campaign" | "full";
  currentValues: Record<string, unknown>;
  businessContext?: {
    businessType?: string;
    companyName?: string;
    city?: string;
    catalogCategories?: string[];
  };
};
```

## Что Arai возвращает

```ts
type ArayFillResponse = {
  fields: Record<string, string | number | boolean | null>;
  summary: string;
  warnings?: string[];
};
```

## Безопасность

- Нельзя генерировать внешние ссылки без подтверждения.
- Нельзя менять цены, остатки, скидки и юридические данные без отдельного подтверждения.
- SEO для личных фото не включается автоматически.
- Для платежей, касс, банков и фискализации Arai только готовит подсказку/черновик, но не подключает реальные ключи без явного шага владельца.

## UX

- Кнопка маленькая, вторичная, с иконкой Sparkles: "Заполнить с Араем".
- Ставится рядом с заголовком блока или рядом с конкретным полем, если заполняется одно поле.
- Пока идет генерация: disabled + "Арай думает".
- После ответа: компактный предпросмотр изменений в `AdminModal` или inline panel.
- Если API недоступен: понятное сообщение без красной паники, через `admin-alert`.
