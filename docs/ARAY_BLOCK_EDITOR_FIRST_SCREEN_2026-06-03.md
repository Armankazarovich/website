# ARAY Block Editor First Screen

Дата: 2026-06-03

## Главная мысль

Первый экран редактора ARAY должен быть похож не на техническую админку, а на спокойный рабочий стол сайта.

Человек видит сайт, нажимает на блок и меняет его. Не ищет код, не читает длинные объяснения, не боится сломать страницу.

## Слои экрана

1. Верхняя панель
   Название проекта, статус, телефон/планшет/десктоп, история, предпросмотр, публикация.

2. Левая панель
   Библиотека сертифицированных блоков: герой, услуги, примеры, процесс, форма, цена, партнер, футер.

3. Центр
   Живой предпросмотр сайта. Блоки можно выбирать, двигать, скрывать и дублировать.

4. Правая панель
   Настройки выбранного блока: текст, кнопки, медиа, цвета, SEO, связи с заявкой или CRM.

5. Нижняя спокойная строка
   “Все сохранено”, “Есть замечания”, “Проверить мобильную версию”, “Готово к публикации”.

## Главные действия

- Нажал на блок.
- Изменил текст.
- Нажал “Сгенерировать вариант”.
- Выбрал лучший вариант.
- Проверил телефон.
- Опубликовал.

## Что нельзя показывать обычному пользователю

- внутренние названия компонентов;
- длинные технические описания;
- сложные схемы связей;
- системные статусы без человеческого смысла;
- лишние предупреждения, если человек сейчас не может по ним действовать.

## Что показывать вместо этого

- что это за блок;
- зачем он нужен;
- что можно изменить;
- какой следующий шаг;
- есть ли проблема на телефоне;
- готов ли блок к публикации.

## Минимальный набор кнопок

- Изменить текст
- Сгенерировать
- Заменить фото
- Цвета
- Скрыть
- Дублировать
- Проверить
- Опубликовать

## Как ARAY защищает качество

Перед публикацией система проверяет:

- заголовок не слишком длинный;
- текст не вылезает из карточек;
- кнопка действия есть;
- блок не пустой;
- телефонная версия не ломается;
- форма ведет в правильную CRM;
- футер ведет обратно в ARAY;
- SEO заполнено хотя бы базово.

## Первый рабочий прототип

Для начала не делаем весь WIX сразу.

Первый прототип должен уметь:

1. открыть сайт ARAY Production;
2. показать список блоков страницы;
3. выбрать блок Hero;
4. изменить заголовок, текст и кнопки;
5. сгенерировать новый текст;
6. переключить телефон/десктоп;
7. сохранить черновик;
8. показать “готово / есть замечания”.

После этого добавляем остальные блоки и переносим принцип на Zeder, PiloRus, Yuva Studio и будущие сайты.

## Закон

Редактор ARAY строится не ради красивой админки. Он строится ради спокойствия: чтобы сайт можно было улучшать каждый день без страха, без ручной верстки и без ощущения, что каждый пиксель держится на нерве основателя.
