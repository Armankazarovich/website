# ARAY — культурное позиционирование

Дата фиксации: 2026-04-30

## Идея

ARAY может стать первым сильным армянским световым AI-продакшеном мирового уровня.

Это важная маркетинговая фича: когда люди видят, что кто-то из их культуры создаёт красивый, честный и технологичный продукт, они начинают гордиться и рассказывать о нём сами.

## Формула

ARAY — армянский по корню, мировой по масштабу.

Смысл:

- корень: Армения, семья, труд, вера, достоинство, тепло, гостеприимство;
- масштаб: продукт для всех стран, языков, профессий, бизнесов и культур;
- тон: гордость без высокомерия, любовь без разделения, сила без агрессии.

## Что можно говорить

- “ARAY Production — световой AI-продакшен с армянским сердцем и мировым взглядом.”
- “Создано человеком, который хочет, чтобы бизнесы и люди росли честно.”
- “Армянский корень, международная платформа.”
- “Технология, которой можно гордиться.”

## Что нельзя делать

- Не строить коммуникацию “для армян против других”.
- Не обещать национальное превосходство.
- Не использовать культуру как дешёвый хайп.
- Не превращать ARAY в локальную игрушку: проект с первого дня должен быть международным.

## Маркетинговый эффект

Если ARAY будет качественным, армянская аудитория может стать первым органическим кругом поддержки:

- делиться продуктом;
- гордиться историей;
- приводить бизнесы;
- помогать с переводами, связями, партнёрствами;
- распространять бренд через доверие.

Но удержит людей не происхождение, а качество продукта. Культурная гордость открывает дверь, качество удерживает.

## Связь с брендом

ARAY должен уважать все культуры. В будущем платформа может иметь:

- 20+ языков;
- локальные партнёрства;
- культурные витрины;
- конкурсы для детей и молодёжи;
- профессиональные сообщества по странам и городам.

Это не только маркетинг, а часть миссии: дать людям путь к профессии, бизнесу и честному заработку.
