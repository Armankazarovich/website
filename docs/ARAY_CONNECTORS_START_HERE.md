# ARAY Connectors Start Here

Дата: 2026-05-07

Этот файл нужен, чтобы подключать ARAY без хаоса: минимум сервисов, понятные расходы, все секреты только в `.env` или `.env.local`.

## Главный принцип

Пользователь видит одного ARAY. Внутри ARAY сам выбирает инструмент:

- GPT / OpenAI — основной мозг, сложные диалоги, планирование, агентская логика.
- Yandex AI Studio — Россия, Wordstat/Search API, фото/текст, SpeechKit, Alice/Smart Home через отдельный OAuth.
- Google Ads Keyword Planner — позже, для мирового спроса, стран, языков и рекламы.
- ElevenLabs — только если нужен отдельный красивый голос; можно заменить SpeechKit.

## Фундамент перед конструктором

Конструктор бизнеса пока не P0. Сначала ARAY должен стабильно уметь подключаться к сервисам, проверять доступы, понимать разрешения, собирать аналитику и не путать обычного человека техническими словами.

Правильный сценарий: человек нажимает `Разрешить`, `Подключить Директ`, `Подключить почту`, `Подключить поиск`, `Настроить голос`. ARAY сам открывает официальный OAuth/кабинет, проверяет доступ, показывает статус и просит минимум данных.

P0:

- AI provider: понять рассказ владельца и превратить его в структуру бизнеса.
- Yandex Search/Wordstat: проверить спрос, регионы, формулировки, сезонность.
- Telegram Bot API, VK Messages и Email SMTP/IMAP: принять первые заявки и уведомления в единый inbox.
- Yandex Metrika: связать сайт, рекламу, заявки, заказы и источники.
- SEO/индексация: Яндекс Вебмастер, Google Search Console, sitemap, robots, метатеги.
- Voice permissions: микрофон, устройства, график, тихие часы, stop-кнопка и журнал доступа.
- Роли и аккаунты: один пользователь может быть владельцем, сотрудником, покупателем, специалистом, фрилансером или блогером; личные и бизнес-доступы не смешивать.

P1:

- Yandex Direct/VK Ads/Google Ads: готовить рекламные черновики и аудитории, запускать только после подтверждения владельца.
- WhatsApp Business Platform: официальный бизнес-канал для входящих и шаблонных сообщений.
- Телефония: звонки, записи, пропущенные, связь с заказом, лидом и задачей.
- Site chat ARAY: все обращения с сайта сразу в inbox и CRM.
- Business/Maps/Profile connectors: карточки бизнеса, отзывы, локальный спрос, бизнесы рядом.
- Бухгалтерия/налоги/ЭДО: СБИС, Контур/Диадок/Эльба, 1С, банки, расходы и напоминания оплат.

P2:

- YouTube, Дзен, VK Clips/Видео, Market и маркетплейсы: контент, товары, услуги и комментарии после проверки API и пользы.
- Партнерские и блогерские сценарии: публикации, промо-размещения, портфолио, монетизация, если есть прозрачные правила.
- Конструктор ARAY: сайт, профиль, каталог, услуги, рекламу и брендбук из рассказа человека - после P0-фундамента.

## P0: что взять сейчас

### 1. Yandex AI Studio

Ссылка: https://aistudio.yandex.ru/docs/ru/ai-studio/operations/get-api-key

Оплата и баланс: https://console.yandex.cloud/billing

Нужно:

- API key из AI Studio.
- Folder ID из Yandex Cloud.
- Активный платежный аккаунт.

В `.env`:

```env
YANDEX_API_KEY="..."
YANDEX_FOLDER_ID="..."
YANDEX_SEARCH_API_TOKEN="..."
YANDEX_WORDSTAT_TOKEN="..."
```

На старте можно использовать один и тот же API key для всех `YANDEX_*_TOKEN`.

Что дает:

- спрос из интернета;
- Wordstat;
- тепловая карта регионов;
- Search API;
- фото/текст через модели AI Studio;
- будущий SpeechKit/голос.

### 1.1. Голос ARAY, разрешения и устройства

Голос должен быть понятным, не пугающим и управляемым:

- ARAY просит микрофон только после действия человека;
- показывает, где он слушает: браузер, PWA, телефон, рабочее место, будущая нативная оболочка;
- дает график работы: всегда вручную, рабочие часы, тихие часы, только выбранные устройства;
- хранит журнал: когда выдали доступ, кто включил, где остановили;
- имеет видимую кнопку стоп.

В `.env`:

```env
ARAY_VOICE_PROVIDER="elevenlabs"
ARAY_STT_PROVIDER="browser"
YANDEX_SPEECHKIT_API_KEY="..."
YANDEX_SPEECHKIT_FOLDER_ID="..."
```

Важно: браузер/PWA может иметь ограничения фонового прослушивания. Если нужно слушать по графику без открытой страницы, понадобится нативная оболочка, kiosk-устройство или официальная интеграция устройства.

## P0: SEO и индексация в один клик

ARAY должен помогать Яндекс/Google бизнесу без технической каши:

- проверить метатеги, sitemap, robots, canonical, скорость и ошибки страниц;
- подключить Яндекс Вебмастер/Метрику и Google Search Console/Analytics;
- подсказать, какие страницы надо доработать;
- подготовить SEO-тексты, но не публиковать критичные изменения без подтверждения;
- показывать обычному человеку "что мешает поиску" и "что сделаю сейчас".

В `.env`:

```env
YANDEX_METRIKA_TOKEN="..."
YANDEX_WEBMASTER_TOKEN="..."
YANDEX_BUSINESS_TOKEN="..."
GOOGLE_ANALYTICS_PROPERTY_ID="..."
GOOGLE_SEARCH_CONSOLE_SITE_URL="..."
GOOGLE_BUSINESS_PROFILE_ACCOUNT_ID="..."
```

### 2. OpenAI / GPT

Ссылка: https://platform.openai.com/api-keys

## P1: Алиса и умный дом

Документация: https://yandex.ru/dev/dialogs/smart-home/doc/en/

Это не тот же ключ, что AI Studio. Нужен OAuth-клиент.

В `.env`:

```env
YANDEX_OAUTH_CLIENT_ID="..."
YANDEX_OAUTH_CLIENT_SECRET="..."
YANDEX_IOT_REDIRECT_URI="https://pilo-rus.ru/api/yandex/iot/callback"
```

Права:

```text
iot:view
iot:control
```

Что даст:

- ARAY видит устройства;
- ARAY запускает сценарии;
- пользователь может управлять через Алису после привязки аккаунта.

В продукте это должно выглядеть просто: пользователь говорит “Арай, включи чайник”, “Арай, выключи свет на складе”, “Арай, запусти вечерний сценарий”. Он не должен знать, что внутри ARAY использовал Алису, OAuth и Smart Home API.

## P2: Google спрос по миру

Keyword Planner API: https://developers.google.com/google-ads/api/docs/keyword-planning/overview

В `.env`:

```env
GOOGLE_ADS_DEVELOPER_TOKEN="..."
```

## P1: Яндекс Директ для каждого бизнеса

Документация по OAuth-токенам: https://yandex.ru/dev/direct/doc/ru/concepts/auth-token

Регистрация OAuth-приложения: https://yandex.com/dev/direct/doc/en/register

Важный принцип: ARAY не тратит рекламные деньги из нашего общего аккаунта. Каждый бизнес подключает свой Яндекс Директ, а расходы идут из его кабинета.

В `.env` для нашего приложения:

```env
YANDEX_DIRECT_CLIENT_ID="..."
YANDEX_DIRECT_CLIENT_SECRET="..."
YANDEX_DIRECT_REDIRECT_URI="https://pilo-rus.ru/api/admin/direct/oauth/callback"
YANDEX_DIRECT_API_URL="https://api.direct.yandex.com/json/v5/"
```

Продуктовый сценарий:

1. Владелец бизнеса нажимает `Подключить свой Директ`.
2. ARAY открывает Яндекс OAuth в pop-up browser или отдельной вкладке.
3. Пользователь разрешает доступ к своему рекламному кабинету.
4. Токен хранится зашифрованно и привязан к бизнесу/пользователю.
5. ARAY готовит кампанию, ключи, аудитории, UTM, минус-слова и бюджет.
6. Платный запуск только после явного подтверждения владельца/админа.

Что нельзя делать:

- запускать рекламу без подтверждения;
- хранить OAuth-токен в `SiteSettings`, `.env` или логах;
- смешивать рекламный бюджет клиента с расходами ARAY;
- показывать обычному человеку техническую кухню OAuth/API.

## Расходы и напоминания

Все платежи записывать в `/admin/aray/costs`.

Этот раздел доступен только `SUPER_ADMIN`.

Что записывать:

- Yandex Cloud / AI Studio — сумма пополнения, тип `prepaid`, день контроля баланса.
- OpenAI API — тип `on_demand`, лимит в кабинете OpenAI.
- Google Ads — тип `on_demand`, подключить позже.
- ElevenLabs — тип `monthly`, только если голос остается отдельно.
- Beget/домен/почта — рублевые регулярные платежи.

Быстрые кабинеты оплат:

- Yandex Cloud: https://console.yandex.cloud/billing
- OpenAI: https://platform.openai.com/settings/organization/billing/overview
- Google Ads: https://ads.google.com/aw/billing/summary
- ElevenLabs: https://elevenlabs.io/app/billing
- Beget: https://cp.beget.com/billing

## Главные возможности ARAY

ARAY главный. Модели, Алиса, поиск, переводчик и OCR — это его инструменты, а не отдельные продукты для пользователя.

ARAY должен уметь:

- фото: распознать товар, брак, документ, накладную, чек, скриншот;
- видео: принять файл, выделить ключевые кадры, описать проблему или сделать выжимку;
- перевод: русский, английский, армянский и другие языки для сайта, заявок, документов;
- поиск: интернет, Wordstat, Google, каталог, заказы, CRM, документы;
- браузер-показ: открыть результат в нашем адаптивном pop-up browser внутри системы;
- документы: прочитать, создать, переписать, отредактировать, подготовить КП, счет, договор, акт, письмо;
- голос: принимать команду голосом и отвечать голосом как ARAY;
- умный дом: управлять устройствами через Алису/Smart Home так, чтобы человек видел только ARAY.

## Правило качества промптов

У ARAY должен быть один системный промпт-оркестратор:

- сначала понять цель человека;
- выбрать инструмент без показа технической кухни;
- если действие опасное или платное, коротко попросить подтверждение;
- не выдумывать данные, если источник не подключен;
- писать обычным языком, без терминов API, токенов и провайдеров;
- результат отдавать сразу в полезном формате: действие, документ, таблица, карточка, браузер-показ или голосовой ответ.

Команда проверки:

```bash
npm run aray:keys
```

Она показывает только `OK / MISS / TODO`, секреты не печатает.
