## 2026-05-11 implemented

- В `/admin/promotion` добавлен блок “Готовность продвижения” и окно `ARAY: Метрика и готовность запуска`.
- Добавлен API `/api/admin/direct/readiness`: хранит номер счетчика Метрики, ID целей и ID организации Яндекс Бизнес в `SiteSettings`.

- Это первый безопасный слой: ARAY сохраняет ID и ведет владельца по Метрике/Direct, но не просит пароль Яндекса и не создает цели через API без отдельного OAuth Метрики.
- Добавлен официальный OAuth Метрики: `/api/admin/metrika/oauth/start`, `/api/admin/metrika/oauth/callback`, `/api/admin/metrika/status`.
- Добавлена операция `/api/admin/metrika/goals`: ARAY создает/переиспользует базовые цели Метрики под Direct и сохраняет их ID для мастера продвижения.
- На витрине добавлен мост событий Метрики: корзина, начало оформления, успешный заказ, клик по телефону и переход в мессенджер отправляют `reachGoal` через общий analytics-слой.
- В `/admin/promotion` добавлен простой SEO/индексация-штурман: sitemap, Яндекс Вебмастер, Google Search Console, Метрика и честные ограничения по индексации.

## Уже делает ARAY

- Создает безопасный черновик без запуска показов.
- Делит каталог на группы по категориям или товарам.
- Передает объявления, ключевые фразы, минус-слова и быстрые ссылки.
- Добавляет UTM на посадочные страницы и быстрые ссылки.
- Ставит дневной бюджет и ручную поисковую стратегию.
- Передает счетчик Метрики, мониторинг сайта и бизнес-профиль, если их ID заполнены в настройках сайта.
- Ограничивает автотаргетинг для первого запуска: включены только целевые запросы без брендов; узкие, широкие, сопутствующие, альтернативные и брендовые запросы выключены.

## Что проверить руками в текущем черновике Direct

1. Метрика и цели
   - На скрине счетчик Метрики не добавлен в кампанию. Это главный следующий шаг перед запуском.
   - Добавить счетчик сайта.
   - Добавить цели: заявка/оформление заказа, клик по телефону, мессенджер, корзина/checkout, вовлеченная сессия.
   - Проставить ценность целей: главная заявка выше, микроконверсии ниже.

2. Мониторинг сайта
   - Включать после добавления счетчика Метрики.
   - Нужен, чтобы Direct останавливал показы при недоступности сайта и не сжигал бюджет.

3. Организация из Яндекс Бизнеса
   - Добавить, если профиль ПилоРус подтвержден и данные совпадают с сайтом.
   - Даст контакты/организацию/карты, но не должен подменять посадочные страницы каталога.

4. Дополнительные элементы объявлений
   - Быстрые ссылки уже выгружаются ARAY, но их надо просмотреть в Direct.
   - Добавить уточнения: `В наличии`, `Склад в Химках`, `Доставка по МО`, `Оплата по счету`, `Помощь с подбором`.
   - Промоакции включать только если есть реальная акция на сайте.
   - Доставку включать только если условия доставки реально описаны и актуальны.
   - Резервную посадочную страницу можно добавить позже; сначала проверить, что основные ссылки живые.

5. Места показа
   - Для первого теста оставить поиск.
   - Товарную галерею включать только после проверки: товарная ссылка, цена, наличие, фото, активная покупка/заказ на странице.
   - РСЯ лучше делать отдельной кампанией после Метрики и первых данных.

6. География
   - Проверить, что регион реально `Москва и область`, а не только Москва.
   - Расширенный геотаргетинг можно оставить включенным, если ключи и регион совпадают с зоной доставки.
   - Если появятся клики из лишних регионов, добавлять исключения и отдельные корректировки.

7. Автотаргетинг
   - Для старта оставить только целевые запросы.
   - Узкие, широкие, сопутствующие, альтернативные и брендовые запросы не включать до статистики.
   - Бренд ПилоРус можно включить позже отдельной брендовой группой/кампанией, если увидим смысл по отчетам.
   - После запуска смотреть отчет поисковых запросов и переносить мусор в минус-слова.

8. Ставки и бюджет
   - Ручная стратегия + 700 ₽/день нормальна для первого теста.
   - Добавить в ARAY отдельный лимит максимальной ставки, чтобы новые условия показа не улетали слишком дорого.
   - Не переходить на автостратегию по конверсиям, пока Метрика/цели не соберут данные.

9. Рекомендации Direct
   - `Автоматически применять рекомендации` пока не включать.
   - Лучше сделать в ARAY блок “Рекомендации Direct”: показать, объяснить риск, применить только после подтверждения.

10. A/B, запреты площадок, персональные скидки
   - A/B — после трафика и гипотез, не до первого запуска.
   - Запреты площадок/IP — после отчетов, без пустых догадок.
   - Персональные скидки Яндекса — только если подключен Яндекс Пэй и есть стратегия/товарная логика под это.
