# ARAY QA: сторис, Direct и запуск рекламы

Дата: 2026-05-21

## Что закреплено

- Сторис-коммерция вынесена в отдельный автоматический guard: `npm run stories:check`.
- Общий quality gate теперь запускает сторис-проверку перед TypeScript и secret scan.
- Сборка проекта проходит: `npm run build`.
- Direct-интеграция проходит статический контроль: `npm run direct:check`.
- ARAY TTS снова проговаривает телефоны цифрами, без странного дикторского произношения.

## Что проверено в браузере

- `/stories`: видны 3 сторис, модалка открывается, есть стрелки, прогресс и кнопка звука.
- `/catalog`: каталог открывается, карточки и размеры видны, сторис-виджет открывается и закрывается.
- `/admin/stories`: админка видит 3 сторис, есть создание, редактирование и ссылки.
- `/admin/promotion`: страница продвижения открывается без ошибок браузера.

## Direct

- OAuth Direct подключен.
- Кабинет отвечает.
- Найдена кампания: `Пилорус каталог`, статус `ACCEPTED`, состояние `OFF`.
- Черновик Direct собирается из каталога.

## Цели Метрики

После проверки сохранены понятные ID целей из уже созданной Метрики:

- счетчик: `108430589`;
- заявка: `544858769`;
- телефон: `544858691`;
- мессенджер: `553647385`;
- вовлеченная сессия: `544858653`.

Для Direct теперь есть главная цель и микроцели. Это достаточно, чтобы не запускать рекламу вслепую.

## Что осталось улучшить позже

- OAuth Метрики пока не подключен, поэтому автоматическое создание/синхронизация новых целей еще не работает.
- Цели `order`, `cart`, `checkout` пока не сохранены, потому что их нельзя честно угадать без точного соответствия в Метрике.

## Следующий безопасный шаг

1. Выгружать Direct только как остановленный черновик.
2. Проверить в Яндексе UTM, регион, дневной лимит и счетчик.
3. Включать показы вручную после финального просмотра кампании.
4. Позже подключить OAuth Метрики, чтобы ARAY сам создавал и синхронизировал цели.
