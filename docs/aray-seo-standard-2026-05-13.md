# ARAY public site SEO standard

Дата: 2026-05-13

## Принцип

SEO делаем не через "плотность ключей", а через полезность страницы, чистую структуру, скорость, внутренние ссылки и доверие. Текст должен помогать покупателю принять решение, а поисковику - понять товар, категорию и регион.

## Товарная страница

- Title: товар + минимальная цена/единица + "купить в Химках с доставкой".
- Description: 120-170 символов из живого описания товара + цена/доставка.
- H1: точное название товара.
- Короткое описание: отдельное поле `shortDescription`, 55-155 символов, одна полезная фраза для карточек и hero.
- Длинное описание: поле `description`, 180-450 символов в блоке "Описание и характеристики".
- Slug: генерируется автоматически из кириллицы в латиницу, очищается и получает суффикс `-1`, `-2`, если URL уже занят.
- Внутренние ссылки: категория, доставка, калькулятор, контакты.
- Schema.org: `Product`, `AggregateOffer`, `BreadcrumbList`, при наличии отзывов - `AggregateRating`.
- Нельзя: повторять ключи механически, писать одинаковые описания для разных товаров, скрывать полезный текст за пустой вкладкой по умолчанию.

## Категория

- Title: категория + регион/производитель/доставка.
- H1: название категории.
- Вверху: товары сразу видны без длинного вступления.
- Под товарами: короткий SEO-блок с пользой, условиями и ссылками.
- Индексируемый URL категории: `/catalog?category=slug`.
- Фильтры и сортировки не продвигаем как отдельные страницы без отдельного спроса.

## Контент для менеджеров

В описании товара обязательно ответить:

- что это за материал;
- где применяется;
- какие важные размеры/сорта/качество;
- как быстро доставляем;
- чем ПилоРус выгоден: производитель, наличие, помощь с расчетом.

Минимум для готовности товара: 180 символов. Хороший диапазон: 180-450 символов.

Для карточек товара отдельный минимум: 55-155 символов в `shortDescription`. Это не SEO-полотно, а короткая продающая польза без списков, канцелярита и набора ключей.

Кнопка `ARAY SEO` должна заполнять сразу оба уровня: короткое описание для карточек и полное описание для товара.

## Типы товаров

Тип товара считается отдельной посадочной SEO-единицей для фильтра, меню, sitemap и страниц вида `/catalog?type=...`.

- У каждого активного типа должны быть `description`, `seoTitle`, `seoDescription`.
- Готовность типа: описание от 160 символов, title 30-120 символов, description 70-220 символов.
- Типы с товарами не скрываем без причины: они должны помогать пользователю быстро выбрать материал.
- Базовые типы и их SEO-тексты хранятся в `lib/product-types.ts`; ручные правки менеджеров лежат в `product_type_settings`.
- Для первичной подготовки и будущих сайтов используется `scripts/backfill-product-type-seo.ts`.

## Внутренняя перелинковка

Каждый товар должен вести минимум на:

- свою категорию;
- доставку и оплату;
- калькулятор объема;
- контакты или менеджера.

Категории должны вести на популярные товары и соседние категории, когда это помогает выбору.

## Технический контроль

- Канонические URL заданы.
- `robots.txt` закрывает корзину, checkout, админку, API и служебные фильтры.
- `sitemap.xml` содержит публичные страницы, категории, типы, товары и статьи.
- Страницы корзины, checkout, wishlist и track закрыты от индексации.
- Навигация должна быть быстрой: без лишних route-level skeleton, с prefetch для категорий и товаров.
