# ARAY / ПилоРус — список на 18.05.2026

Дата подготовки: 17.05.2026  
Цель: завтра не распыляться, а закрывать только то, что реально двигает проект к боевому запуску.

## Статус на утро

- Витрина ПилоРус локально стабильна: карточки, размеры, price/list/grid views, корзина, checkout и базовые страницы проверены на телефоне и десктопе.
- Мобильные popup-окна размеров укреплены: узкие iPhone больше не должны резать карточки размеров.
- Админка локально открывается в ключевых разделах на телефоне и планшете без критичных переполнений.
- CRM-автоматизации стали чище: декоративные emoji убраны из вывода сценариев.
- Direct, analytics, finance и ARAY assistant проходят свои технические проверки.

## Завтра P0

1. Добавить и проверить обязательные ключи:
   - `YANDEX_API_KEY`
   - `YANDEX_FOLDER_ID`
   - `YANDEX_SEARCH_API_TOKEN`
   - `YANDEX_WORDSTAT_TOKEN`
2. После ключей запустить `npm run aray:keys` и довести required-блок до зеленого статуса.
3. Настроить или подтвердить боевые каналы связи: SMTP и Telegram.
4. Проверить production после деплоя на телефоне: каталог, popup размеров, корзина, checkout, админка, CRM automation.
5. Решить SEO-предупреждение по телефонам на главной: либо продублировать телефоны в статическом слое, либо зафиксировать как осознанный динамический вывод.

## Завтра P1

1. Direct readiness passport: Метрика, цели, регион, быстрые ссылки, минус-слова, UTM, организация, подтверждение владельца.
2. Документы перед платным трафиком: оферта, возврат, доставка, оплата, реквизиты продавца, политика персональных данных, согласия на формах.
3. Конструктор не начинать вразнос: сначала определить первый полезный кусок — бриф магазина, паспорт проекта, черновик витрины, каталог, CRM-скелет.
4. Разобрать старые lint-предупреждения по hooks/alt text отдельной спокойной задачей, без смешивания с запуском.

## Честные блокеры

- ARAY знания/спрос/поиск не будут полноценными без Yandex AI/Search/Wordstat ключей.
- Direct нельзя запускать “в бою” без реального кабинета, Метрики, целей и подтверждения владельца.
- Юридический блок требует отдельной финальной сверки. Сейчас технически страницы есть, но это не юридическое заключение.
- Платежи, фискализация, возвраты и подписки нельзя обещать как автоматические, пока не подключены провайдеры и правила учета.

## Рекомендованный порядок дня

1. Ключи и каналы связи.
2. Production smoke на телефоне.
3. Direct/Метрика паспорт.
4. Документы и юридический минимум.
5. Только после этого — первый аккуратный кусок конструктора.
