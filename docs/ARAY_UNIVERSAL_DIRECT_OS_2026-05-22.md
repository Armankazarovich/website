# ARAY Universal Direct OS

Дата: 2026-05-22

Статус: универсальный закон запуска Direct для ПилоРус и будущих бизнесов.

## Цель

Direct не должен быть ручной болью на каждом новом проекте.

ARAY должен работать так:

бизнес → домен → каталог → регион → Метрика → цели → фид → горячие группы → минус-фразы → остановленный черновик → ручная проверка → ручной запуск.

## Что Уже Универсально В Коде

- `lib/direct-campaign-draft.ts`
  - собирает черновик из каталога;
  - умеет группировать по категориям или товарам;
  - фильтрует товары по цене и наличию;
  - добавляет UTM;
  - добавляет минус-слова;
  - управляет бюджетом, ставкой, графиком и регионом.

- `app/api/admin/direct/draft/route.ts`
  - берет tenant-настройки бизнеса;
  - определяет публичный домен;
  - проверяет Direct-подключение;
  - определяет регион Direct;
  - подтягивает счетчик и цели Метрики;
  - собирает готовность рекламного пакета.

- `lib/aray-direct-package.ts`
  - считает готовность запуска;
  - разделяет поиск, товарные кампании, сети, ретаргетинг и медийку;
  - не обещает то, что еще не подключено;
  - защищает бюджет от автозапуска.

- `lib/yandex-direct-export.ts`
  - создает кампанию через Direct API;
  - добавляет группы, объявления, ключи, быстрые ссылки и уточнения;
  - после создания оставляет кампанию остановленной;
  - требует подтверждение владельца.

- `/admin/promotion`
  - дает один маршрут запуска;
  - показывает готовность;
  - дает полные настройки;
  - умеет “боевой черновик за 1 клик”;
  - показывает чек-лист перед запуском.

## Что Должен Заполнить Каждый Новый Бизнес

Минимум:

- домен;
- название бизнеса;
- регион показа;
- телефон;
- каталог или услуги;
- цены;
- наличие или правило наличия;
- счетчик Метрики;
- цели: заявка, телефон, мессенджер, вовлеченная сессия;
- Direct OAuth/token.

Желательно:

- Яндекс Бизнес / Карты;
- фото;
- отзывы;
- доставка;
- акции;
- отдельные посадочные страницы.

## Универсальные Режимы Запуска

### 1. Осторожный Поиск

Для первого дня.

- Только Поиск.
- Горячие коммерческие запросы.
- Малый дневной бюджет.
- Минус-фразы.
- Рабочее время.
- Только товары с ценой и наличием.
- Черновик остановлен.

### 2. Товарный Спрос

После проверки фида и Метрики.

- Товарные карточки.
- Цена.
- Фото.
- Наличие.
- Ссылки на товары.
- Счетчик Метрики.

### 3. Возврат Посетителей

После накопления трафика и целей.

- посетители каталога;
- посетители карточек;
- корзина;
- оформление;
- звонок;
- мессенджер.

### 4. Медийка И Охват

Только после того, как поиск доказал экономику.

- отдельный бюджет;
- отдельные креативы;
- отдельная оценка результата.

## Закон Безопасности

ARAY может:

- собрать черновик;
- объяснить риски;
- предложить фразы;
- добавить минус-слова;
- подготовить UTM;
- подготовить чек-лист;
- выгрузить остановленную кампанию после подтверждения.

ARAY не может:

- включать показы без владельца;
- тратить бюджет сам;
- обещать заявки без статистики;
- смешивать поиск, сети и медийку в один неконтролируемый запуск;
- скрывать отсутствие Метрики, целей, домена или региона.

## Быстрый Запуск Для ПилоРус

ПилоРус запускается через режим “Осторожный Поиск”.

Основной фокус:

- пиломатериалы Химки;
- купить доску;
- доска обрезная цена;
- вагонка купить;
- брус купить;
- доставка пиломатериалов;
- пиломатериалы с доставкой.

Цели:

- заявка;
- телефон;
- мессенджер;
- вовлеченная сессия.

Старт:

- черновик Direct;
- ручная проверка в Яндексе;
- ручное включение;
- ежедневная чистка поисковых запросов и минус-фраз.

## Быстрый Запуск Для Стройматериалов

Стройматериалы запускаются тем же маршрутом.

Отличаются только:

- домен;
- tenant;
- регион;
- каталог;
- категории;
- цели;
- тексты и фразы.

Код Direct менять не нужно, если данные бизнеса заведены правильно.

## Что Еще Нужно Доделать Для Полного Спокойствия

1. Экран “профиль рекламного запуска” для каждого tenant.
2. Наборы фраз по нишам: пиломатериалы, стройматериалы, услуги, доставка.
3. Автоматический отчет “что мешает запуску”.
4. Ежедневный разбор поисковых запросов после запуска.
5. Кнопка “добавить мусорные фразы в минус-слова”.
6. Контроль цены заявки после первых конверсий.

## Статус

Direct уже строится как универсальная система.

Первый запуск должен быть осторожным, контролируемым и ручным по бюджету.

После первых данных ARAY сможет помогать сильнее: чистить фразы, усиливать группы, находить слабые карточки и готовить следующий рекламный слой.
