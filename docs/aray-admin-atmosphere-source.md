# ARAY Admin Atmosphere Source

Главный живой источник фото-фонов для единой админки ARAY:

```text
D:\ARAY PRODUCTION\ФОН ДЛЯ ПЛАТФОРМЫ
```

Арман обновляет и добавляет новые фоновые изображения именно там. При работе с палитрами и атмосферой админки сначала смотреть эту папку.

Продуктовое правило:

- Эти 9 фото используются только в админке: админка у всех проектов одна и должна выглядеть мощно, современно, функционально и из будущего.
- Цветовую атмосферу и палитры интерфейса можно переиспользовать шире: ПилоРус, админка, кабинет и будущие сайты могут брать похожие цвета, чтобы стиль ARAY узнавался.
- Клиентские публичные сайты не должны брать эти админские фоновые фото. Для них визуалы подбираются или генерируются под сферу бизнеса; часто публичному сайту лучше оставить чистый фон без большого фото.
- Для будущих клиентов собирать отдельные эталоны по каждой сфере: своя идеальная визуальная форма бизнеса, свои релевантные изображения и свой уровень "вау", без копирования админских фонов.

Правило для сайта:

- Не подключать изображения напрямую с `D:\...`.
- Отобранные фоны копировать и сжимать в `public/images/admin-atmosphere/`.
- В коде использовать только публичные пути вида `/images/admin-atmosphere/name.webp`.
- Сохранять 9 осмысленных атмосфер админки: вода/интеллект, земля/золото, ночной фокус, северный свет, лесной баланс, город будущего, солнечный импульс, космос данных, тихая роскошь.
- Правило палитра -> фото админки хранится в `lib/admin-atmospheres.ts`.
