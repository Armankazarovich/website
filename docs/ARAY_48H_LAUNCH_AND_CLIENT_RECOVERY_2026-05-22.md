# ARAY 48H Launch And Client Recovery

Дата: 2026-05-22

Статус: антикризисный план запуска ПилоРус, Direct и второго магазина.

## Главный Принцип

Сейчас цель не изобрести еще один слой, а вернуть доверие, деньги и спокойствие.

На 48 часов включается режим сдачи:

- новые идеи не добавляются в релиз;
- доделываются только ошибки, которые мешают запуску, оплате, заявке, звонку, корзине, каталогу, рекламе или доверию;
- все остальное уходит в очередь после запуска;
- лучше честный стабильный запуск с понятным планом улучшений, чем бесконечная идеальная версия без денег.

## ПилоРус: Что Уже Можно Считать Сильным

- Каталог и карточки доведены до серьезного визуального уровня.
- Сторис-коммерция есть и проверяется отдельным guard.
- Direct OAuth подключен.
- Кампания `Пилорус каталог` найдена, статус `ACCEPTED`, состояние `OFF`.
- Цели Метрики сохранены:
  - счетчик `108430589`;
  - заявка `544858769`;
  - телефон `544858691`;
  - мессенджер `553647385`;
  - вовлеченная сессия `544858653`.
- Реклама не должна включаться вслепую: только остановленный черновик, затем ручной просмотр и запуск.

## ПилоРус: Минимальный Честный Релиз

Запуск считается допустимым, если работают:

- главная;
- каталог desktop/mobile;
- карточка товара desktop/mobile;
- фильтры и размеры;
- корзина;
- оформление заявки;
- телефон и формы связи;
- сторис не мешают покупке;
- админка открывает заказы, товары, сторис, продвижение;
- Direct готов как остановленный черновик;
- Метрика получает главные цели.

Не блокируют запуск:

- идеальный редактор услуг;
- глубокий конструктор ролей;
- полная автоматизация документов;
- полный ARAY-директор;
- дополнительные вау-эффекты;
- будущие логистические биржи.

## Direct: Безопасный Запуск

1. Прогнать `npm run direct:check`.
2. Открыть `/admin/promotion`.
3. Создать или обновить черновик Direct.
4. Убедиться, что кампания остается выключенной.
5. В Яндексе вручную проверить:
   - домен;
   - UTM;
   - регион;
   - дневной лимит;
   - счетчик Метрики;
   - цель заявки;
   - цель телефона;
   - тексты объявлений;
   - ссылки на каталог и товары.
6. Только после этого включать показы вручную.

## Второй Магазин Стройматериалов

Цель: не ждать полного ARAY Store Pro, а быстро сдать рабочий магазин на основе уже готовой системы.

Минимальный релиз:

- главная;
- каталог;
- карточки товаров;
- корзина или форма заявки;
- контакты;
- базовая админка товаров/заказов;
- базовое SEO;
- Метрика;
- ручной рекламный запуск позже.

Что переносим из ПилоРус:

- карточки;
- каталог;
- мобильный UX;
- корзина;
- заявки;
- админку;
- медиа;
- базовую структуру Direct.

Что не переносим в первый релиз:

- сложный ARAY-конструктор;
- весь набор сторис;
- глубокую CRM;
- документы и логистику.

## Разговор С ПилоРус

Текст:

> Я довел проект до состояния запуска, потому что хотел не просто сайт, а систему с каталогом, заявками, Метрикой и Direct. Сейчас мы переходим в режим сдачи: финальная проверка, безопасный черновик рекламы, ручной запуск показов после проверки бюджета, региона и целей. Я не буду добавлять новые функции до запуска, только исправления, которые мешают продаже.

## Разговор Со Стройматериалами

Текст:

> Я понимаю, что ожидание затянулось, и беру ответственность. Чтобы не держать вас дальше, предлагаю запустить первый рабочий релиз магазина: каталог, карточки, заявки, контакты и базовая админка. После запуска уже будем добавлять расширенные функции. Так вы начнете получать заявки, а не ждать идеальную систему без результата.

## Личное Правило На Сейчас

Сначала вернуть движение:

- один видимый запуск;
- один честный разговор с клиентом;
- один понятный срок;
- один список того, что входит сейчас и что идет после.

Не обещать “все сразу”.

Обещать честно: “сейчас запускаю рабочее, потом развиваем”.

## План На 48 Часов

### День 1

1. Заморозить новые функции ПилоРус.
2. Прогнать проверки:
   - `npm run direct:check`;
   - `npm run stories:check`;
   - `npm run content:check`;
   - `npm run quality`;
   - `npm run build`.
3. Пройти руками:
   - главная;
   - каталог;
   - карточка;
   - корзина;
   - заявка;
   - admin promotion.
4. Сформировать короткий список только блокеров.
5. Написать клиенту ПилоРус честный статус и срок.

### День 2

1. Исправить только блокеры.
2. Развернуть или обновить прод.
3. Проверить прод:
   - главная;
   - каталог;
   - товар;
   - заявка;
   - Метрика;
   - Direct draft.
4. Отправить ПилоРус ссылку и инструкции.
5. Начать быстрый перенос второго магазина как отдельный релиз.

## Стоп-Лист До Запуска

До получения первого запуска и оплаты не трогать:

- новые глобальные модули Арая;
- логистическую биржу;
- сложные документы;
- глубокие кабинеты ролей;
- новый дизайн без прямой причины;
- любые “вау” функции, если они не помогают сдать сайт.

## Следующий Рабочий Шаг

Проверить ПилоРус как запуск:

1. Direct.
2. Каталог.
3. Корзина и заявка.
4. Мобильная версия.
5. Продвижение.
6. Только после этого решать стройматериалы.
