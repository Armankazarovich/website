# ARAY Store Pro Roadmap

Дата: 2026-05-13

## Закреплено в эталоне

- Единая карточка товара для каталога, хитов, похожих и рекомендаций.
- Отдельные поля товара: `shortDescription` для карточек и `description` для полного SEO-описания.
- `ARAY SEO` заполняет короткое и полное описание товара.
- Slug товара генерируется из кириллицы в латиницу и защищается от дублей через `-1`, `-2`, `-3`.
- Типы товаров стали SEO-посадочными: фильтр, меню, sitemap, title, description и описание раздела.
- Покупка `м³/шт` в карточке работает через чистую кнопку цены и компактный выбор единицы только по намерению.

## Следующие задачи магазина

- Категории: быстрое добавление из карточки товара, родительские/дочерние категории, сортировка, синхронизация меню и sitemap.
- Атрибуты и фильтры: добавление, редактирование, скрытие, порядок, связь с товарами и ARAY-автозаполнение.
- Доставка: габариты, вес, упаковка, единицы измерения и поля для расчета логистики.
- Массовое редактирование: цены, наличие, категории, типы, описания, атрибуты, единицы продажи.
- Промокоды, бонусы и маркетинговые правила.
- Оптовые цены, розница/опт, режим "войти, чтобы увидеть цены".
- Режим каталога без корзины для проектов, где нужен только запрос менеджеру.
- Акции: адаптивный ряд из 2-3 карточек, при 4+ карточках карусель из единого источника с главной и страницы акций.

## Правило

Все функции должны работать как модуль ARAY Store Pro: менеджер управляет контентом, ARAY помогает заполнять и проверять, публичный сайт сохраняет единый дизайн, SEO и скорость.
