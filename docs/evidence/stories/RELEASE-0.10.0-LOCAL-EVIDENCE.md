## Особенности, найденные при проверке

- Локальный `next start` не отдаёт файлы, появившиеся в `public/` после его
  запуска (404) — после сжатия его нужно перезапускать. На боевом видео
  отдаёт nginx напрямую (сильный ETag формата nginx), там этого нет.
- Обложки: обработчик их делает, но при переводе уже существующей сторис не
  подставляет — три сторис остаются без обложки. Долг.
- Короткие MP4 до 24 МБ не перекодируются: оглавление в конце стоит им ~0,1 с
  (замер: запрос на открытом соединении 0,05–0,13 с). Оставлено как есть.
