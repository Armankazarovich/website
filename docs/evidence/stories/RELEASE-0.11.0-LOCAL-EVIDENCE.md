## Путь менеджера (вход владельца, база для пробы)

- Загрузка MOV 57,8 МБ через «Создать» → «Видео в очереди» за 5 с → «Видео готово» за 35 с; лёгкая копия и обложка подставились в форму сами.
- Ролик 200 с — отказ в браузере за 4 с: «Видео длиннее 3 минут (3:20). Обрежьте его или разделите на две сторис.»; уже загруженное видео не затёрто.
- Обработчик: ролик 179 с — готов за 26 с; 185 с — отказ за 2 с с понятной причиной.
- «Облегчить видео» — без окна, статус на карточке, «Вернуть как было» — без окна; оба работают на экране.
- «Скрыть» — без окна, строка «…скрыта с сайта · Вернуть»; «Вернуть» вернул сторис на сайт.
- «Порядок» — перетаскивание за ручку 44×44 и стрелки; порядок сохранился после перезагрузки.
- «Статистика» — небольшое окно: всего, на сайте, скрыто, с товаром, онлайн-продавец, просмотры, три самых смотримых.
- Шаблон «Товар» ставит только заголовок; подпись и описание пустые, с подсказками.

## Репетиция перевода шести боевых сторис

Четыре тяжёлые и MOV-сторис переведены в лёгкие копии тем же кодом, что за
кнопкой; две короткие MP4 оставлены (оглавление в конце стоит им ~0,1 с —
замер запроса на открытом соединении 0,05–0,13 с). У каждой изменилась только
ссылка на видео; исходники целы; откат вернул исходную ссылку.
